# Veera Arun — Developer Portfolio 💻

A personal portfolio website showcasing my projects, technical skills, education, achievements, and contact information. The site is built from scratch with **HTML, CSS, and vanilla JavaScript**.

## 🌐 Portfolio

The repository contains the source code for my personal developer portfolio.

## ✨ Features

- Full-screen loading experience.
- Single-page navigation.
- Smooth scrolling between sections.
- Active navigation state based on the current section.
- Projects showcase with live and GitHub links.
- Skills section.
- Education and coursework.
- Achievements section.
- About-me section.
- Contact links.
- Responsive layout.
- Resume link.
- Project thumbnails and visual assets.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Intersection Observer API
- Google Fonts / web assets
- No frontend framework
- No backend

## 📁 Project Structure

```text
Portfolio/
├── index.html       # Main portfolio page
├── scripts.js       # Navigation, loader and interaction logic
├── styles/          # Site styles
├── scripts/         # Supporting JavaScript
├── assests/         # Images, thumbnails and graphics
└── README.md
```

## 🧠 JavaScript Functionality

The portfolio uses vanilla JavaScript for:

- Delayed loader dismissal.
- Smooth navigation to the contact section.
- Active navigation highlighting.
- Intersection Observer-based section detection.
- Scroll-aware navigation state.
- Keyboard-friendly navigation interactions.

## 🚀 Run Locally

No build step is required.

```bash
git clone https://github.com/Veeraarun/Portfolio.git
cd Portfolio
```

Open `index.html` directly or serve the directory with a local static server.
